# Lab guide

1. Draw your home lab topology: ISP router, wireless access point, laptop, phone, and any managed switch.
2. Record each device's expected IP and role from your router's admin page; redact public IPs and identifiers before publishing.
3. Run the monitor only on your own private subnet with explicit authorization.
4. Compare reachable devices to your router inventory. Investigate unknown entries manually; reachability does not identify ownership.
5. For Network & Systems Analyst practice, document how DHCP leases, DNS resolution, gateway settings, Wi-Fi signal, switch port/VLAN assignment, and firewall policy affect connectivity. This project observes; it does not change configurations.
